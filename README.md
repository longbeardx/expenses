# Expenses

A tiny, installable web app for logging expenses fast and seeing each month's total.

- Open → type amount → tap category → **Add**. Two taps.
- Monthly total, per-category bars, delete with ✕, previous/next month.
- Works offline, installs to the home screen (Chrome: ⋮ → *Add to Home screen*).
- **Data stays on the device** (browser storage). Nothing is sent anywhere.
- Export / Import CSV for backups. Importing the same file twice adds nothing twice.

Hosted with GitHub Pages. Updates load on the next open while online.
